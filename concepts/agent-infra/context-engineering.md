# Context Engineering
Context engineering is the discipline of deciding what actually goes into the model's context window at each step—instructions, retrieved documents, tool results, prior turns, memory—and what gets left out. Because context windows are finite and every token competes for the model's attention, careless assembly leads to distraction, drift, or missed information even when the underlying model is capable. Good context engineering treats the prompt as an assembled artifact rather than a static template, curating and compressing information so the agent sees exactly what it needs to make its next decision.
