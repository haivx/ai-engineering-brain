# Context Engineering
Context engineering là kỷ luật quyết định thứ gì thực sự được đưa vào context window của model ở mỗi bước — chỉ dẫn, tài liệu truy xuất được, kết quả tool, các lượt trước, memory — và thứ gì bị bỏ ra ngoài. Vì context window là hữu hạn và mọi token đều cạnh tranh sự chú ý của model, ráp context cẩu thả sẽ dẫn tới phân tán, trôi hướng, hoặc bỏ sót thông tin ngay cả khi model bên dưới đủ giỏi. Context engineering tốt coi prompt là một tạo tác được lắp ráp chứ không phải một template tĩnh, chọn lọc và nén thông tin sao cho agent nhìn thấy đúng thứ nó cần để ra quyết định tiếp theo.
